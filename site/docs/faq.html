FAQ & Support Policy

Answers to common questions about encryption, recovery, Windows startup, Unity excludes, Cloudflare R2 pricing, privacy, and support scope.

Frequently Asked Questions

Does Restic Tray start automatically when I sign in to Windows?

Not automatically yet. Because scheduled backups and overdue notifications only run while Restic Tray is running, place a shortcut to restic-tray.exe --minimized in your Startup folder (Win + R → shell:startup). See Start automatically on Windows sign-in.

Can I restore my data if I lose my PC? What if I forget the repository password?

Yes, as long as you kept a copy of your Restic repository password outside the PC (you can always issue a new Cloudflare R2 API token). Because credentials.dat is encrypted with Windows DPAPI tied to the original PC and Windows user, it cannot be decrypted elsewhere — if the repository password is lost, the encrypted data in R2 cannot be recovered.

Can Cloudflare read my backed-up files?

No. Restic encrypts all file contents, filenames, and metadata on your PC using AES-256-CTR with Poly1305-AES authentication before uploading to R2, and your repository password never leaves your machine.

Why is Unity's Library folder not included in my backups?

Unity’s Library, Temp, Logs, obj, Build, Builds, and Assets\SerializedUdonPrograms directly under a Unity project root are regenerable caches/outputs and are excluded by default (useBasicExcludes: true) to save storage space and upload time. Identically named folders inside Assets or Packages are still backed up. Turn off 基本の除外パターンを有効にする on the フォルダ page if you want generated folders backed up too.

Can I back up Git repositories too?

Yes. Restic Tray backs up the entire folder including .git (excluding only Git’s temporary .git/objects/pack/tmp_pack_* files), preserving uncommitted changes, stashes, and unpushed commits. However, .git folders cannot be assigned a multi-PC projectKey — use Git itself to sync code across machines.

How much does Cloudflare R2 cost?

See Cloudflare R2 Pricing for current storage, operation, and free-tier terms. R2 charges zero egress fees, and Restic’s chunk deduplication combined with Restic Tray’s default cache excludes helps keep stored volume low. Note that Cloudflare requires a payment method on file to enable R2 even within the free tier.

Why does Windows SmartScreen warn when I run the installer?

Initial releases are distributed unsigned, so Windows Defender SmartScreen may warn on first launch. Verify SHA256SUMS.txt and gh attestation verify as described in Verify Checksums & Build Provenance before running.

Will Restic Tray support other cloud storage providers, macOS/Linux, or an English UI?

The current project scope is Windows 10 / Windows Server 2016 or later (x64, TLS 1.2+), Cloudflare R2, and a Japanese desktop UI. Feature requests outside this scope are welcome in GitHub Issues for discussion, without a commitment to implement them.

Does Restic Tray send data anywhere other than my Cloudflare R2 bucket?

No. There is no author-operated server, no analytics or telemetry, and no automatic update check network traffic.

How do I get notified about new releases?

Restic Tray has no built-in update checker. To receive release alerts, click Watch → Custom → Releases at the top of the nayuengin/restic-tray GitHub repository.

Support Policy & Disclaimer

  • Supported versions: Only the latest release receives bug fixes and security updates. Older versions are not backported.
  • No SLA: Maintained on a best-effort basis by the owner (@nayuengin) with AI-assisted maintenance and no guaranteed response timelines.
  • Semantic Versioning: Follows SemVer; breaking changes occur only in major versions and include migration notes in CHANGELOG.md.
  • Project scope: Windows 10 / Windows Server 2016 or later (x64, TLS 1.2+), Cloudflare R2, and Japanese desktop UI.
  • Backup responsibility: In addition to the MIT License warranty disclaimer, Restic Tray does not guarantee the integrity or recoverability of your backups. Always test restoring your data periodically using both the built-in restore verification and manual test restores.
  • Security reporting: Report vulnerabilities privately via GitHub Private Vulnerability Reporting rather than public issues.
