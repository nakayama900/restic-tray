Restic Tray Documentation

Guides for installing, configuring Cloudflare R2, automating encrypted backups, integrating MCP agents, and recovering your files on Windows.

Before you begin
  • Platform: Windows 10 / Windows Server 2016 or later (x64) with TLS 1.2+.
  • Storage: Cloudflare R2 (native S3-compatible backend, standard restic repository format).
  • Desktop UI language: The Windows GUI and built-in MCP tool descriptions are currently Japanese only. English documentation includes the exact Japanese labels shown on screen so you can follow along smoothly.
  • Unofficial software: Independent MIT-licensed OSS not affiliated with restic or Cloudflare.

Recommended Reading Order

  1. Installation & Verification — Download v1.0.0, verify SHA256SUMS.txt and build attestation, and configure Windows sign-in startup.
  2. Initial Setup & Cloudflare R2 — Create a dedicated R2 bucket and least-privilege API token, save DPAPI credentials, and initialize the repository.
  3. Basic Usage — Add folders, verify built-in excludes, set a schedule, and understand periodic restore checks.
  4. Backup & Restore — Run your first dry-run, test restoring to a separate folder, and bookmark the standalone CLI recovery steps.
  5. MCP Integration — Optionally connect Claude Code, Claude Desktop, or Cursor to the built-in 22-tool MCP server.
