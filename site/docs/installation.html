Installation & Verification

Install Restic Tray v1.0.0 on Windows x64, verify SHA-256 checksums and build provenance, and configure automatic minimized startup.

System Requirements

  • OS: Windows 10 / Windows Server 2016 or later (64-bit x64).
  • TLS: TLS 1.2 or later (required by the bundled official restic.exe v0.20.0).
  • Storage: A Cloudflare account with an R2 bucket and API token (covered in Initial Setup & Cloudflare R2).
  • Dependencies: None for release bundles — pure Rust native executable with no WebView2 or Visual C++ runtime installation required.

Download from GitHub Releases

Download the bundle that fits your workflow from GitHub Releases. All three packages include the pinned, SHA-256-verified official restic.exe v0.20.0.

Restic Tray v1.0.0 Windows x64 release packages
Package Filename Install Path & Notes
NSIS Installer (Recommended) Restic.Tray_1.0.0_x64-setup.exe Per-user install under %LOCALAPPDATA%\Programs\Restic Tray. Safely upgrades even while the tray app or --mcp is running.
MSI Installer Restic.Tray_1.0.0_x64_ja-JP.msi Per-user Windows Installer package for standard MSI deployment.
Portable ZIP Restic.Tray_1.0.0_x64-portable.zip Extract anywhere and run restic-tray.exe directly. Bundles restic.exe alongside the executable.

Verify Checksums & Build Provenance

Unsigned initial releases & SmartScreen

Initial releases are distributed without code signing. On first launch, Windows Defender SmartScreen may display “Windows protected your PC” — verify the file using the steps below first, then select More info → Run anyway. On Windows 11 systems with Smart App Control enforced, unsigned binaries may be blocked.

Download SHA256SUMS.txt from the same release alongside your installer, then run both checks in PowerShell:

PowerShell 
# 1. Compare SHA-256 hash against SHA256SUMS.txt
Get-FileHash -Algorithm SHA256 .\Restic.Tray_1.0.0_x64-setup.exe
Get-Content .\SHA256SUMS.txt

# 2. Verify GitHub Artifact Attestation (requires GitHub CLI `gh`)
gh attestation verify .\Restic.Tray_1.0.0_x64-setup.exe --repo nayuengin/restic-tray

Official release artifacts are built exclusively on GitHub-hosted runners via .github/workflows/release.yml and attested with GitHub Artifact Attestations.

Start Automatically on Windows Sign-In

Important for scheduled backups

Restic Tray does not currently register a Windows startup entry automatically. Scheduled backups and overdue notifications only run while Restic Tray is running. After a reboot, backups stay paused until the app launches.

To launch Restic Tray minimized to the system tray whenever you sign in:

  1. Press Win + R, type shell:startup, and press Enter to open your user Startup folder.
  2. Right-click inside the folder and create a new shortcut pointing to restic-tray.exe with the --minimized flag:
Shortcut Target 
"%LOCALAPPDATA%\Programs\Restic Tray\restic-tray.exe" --minimized

If you use the Portable ZIP edition, replace the path with the folder where you extracted restic-tray.exe.

Updating & Release Notifications

  • No built-in update checker: Restic Tray never phones home. To receive release notifications, click Watch → Custom → Releases on nayuengin/restic-tray.
  • Upgrading: Download and verify the new NSIS installer and run it over your existing install (safe even if the tray app or --mcp is running).
  • Uninstalling: Removing Restic Tray does not delete %LOCALAPPDATA%\io.github.nayuengin.restic-tray\ or your Cloudflare R2 bucket data. Delete them manually if you want a full wipe.

Build from Source (Optional)

Prerequisites on Windows x64: Rust stable toolchain (MSRV 1.95, x86_64-pc-windows-msvc), Visual Studio C++ Build Tools, and PowerShell 7 (pwsh). Building installers additionally requires NSIS (makensis.exe), WiX Toolset 3.14 (candle.exe / light.exe), and Python 3.

PowerShell 
git clone https://github.com/nayuengin/restic-tray.git
cd restic-tray

# Download and SHA-256-verify the pinned official restic.exe (v0.20.0)
pwsh -NoProfile -File scripts/download-restic.ps1

# Run in development mode
cargo run

# Build optimized release binary (target/release/restic-tray.exe)
cargo build --release --locked
