Why choose Restic Tray over Git or ad-hoc scripts?

Git tracks committed history; Restic Tray backs up your entire live working directory so you can recover any folder as it existed on a past day.

Git is not a backup

Uncommitted edits, untracked notes, stashes, unpushed branches, and heavy Unity binary assets are lost if your drive fails. Restic Tray snapshots entire folders — including .git — while excluding regenerable caches like node_modules/, target/, and Unity’s Library/.

Client-side encrypted, zero app lock-in

Restic encrypts every file and filename on your PC with AES-256-CTR and Poly1305-AES before upload, deduplicating at the chunk level. Your repository password never leaves your machine, and you can restore everything with the standalone restic CLI even without this app.

Zero-egress Cloudflare R2 — your bucket, your keys

Cloudflare R2 works directly with Restic’s built-in s3: backend and charges zero download bandwidth fees, so full restores and periodic read-back checks stay predictable. There is no author-operated server, no telemetry, and no background phone-home traffic.

Quiet pure-Rust tray resident + MCP

Built with eframe/egui and tray-icon — no Electron or WebView. Minimized to the system tray, rendering stops completely so idle CPU stays near zero while the scheduler, overdue alerts, and local Named Pipe MCP bridge keep running.

What features and safeguards are built in?

Restic Tray enforces secret isolation, automated read-back verification, local audit logging, and opt-in destructive guards by default.

DPAPI Secret Isolation

R2 keys and the Restic repository password are encrypted with Windows DPAPI + secondary entropy + Zeroize into config\credentials.dat. Secrets never touch config.json or CLI arguments.

Automated Restore Verification

Runs restic check --read-data-subset (default: 5% every 7 days) and raises a Windows toast alert if verification fails or no backup succeeds within your threshold (default: 48 hours).

Built-in 22-Tool MCP Server

Connect Claude Code, Cursor, or Claude Desktop via restic-tray.exe --mcp. Inspect status, run dry-runs, diff snapshots, and restore safely while prune, storage deletion, and handoff stay opt-in.

Explore all 22 MCP tools

Smart & Unity-Aware Excludes

Built-in excludes skip build/dependency caches, excludeIfPresent markers (CACHEDIR.TAG, SourceAssetDB, pyvenv.cfg), and Unity project-root outputs without touching assets inside Assets/ or Packages/.

Local SQLite (WAL) History & Audit

Records every backup run (new/changed files, size delta, stored bytes, snapshot ID, duration) alongside GUI, tray, and MCP audit logs in r2_restic_history.db.

Multi-Guard R2 Cleanup & Handoff

Pure-Rust S3 client for safe prefix/bucket cleanup with dry-run counts, exact bucket-name input, and a 1.5-second hold button. Also includes experimental single-writer multi-PC project handoff.

Unsigned initial releases & verification

Initial releases are distributed unsigned. Windows Defender SmartScreen may display “Windows protected your PC” on first run (verify first, then select More info → Run anyway), and Windows 11 Smart App Control may block unsigned binaries. Verify downloads with both SHA256SUMS.txt and GitHub Artifact Attestations before running.

PowerShell 
# 1. Verify SHA-256 checksum against SHA256SUMS.txt from the same release
Get-FileHash -Algorithm SHA256 .\Restic.Tray_1.0.0_x64-setup.exe
Get-Content .\SHA256SUMS.txt

# 2. Verify GitHub Artifact Attestation (requires GitHub CLI `gh`)
gh attestation verify .\Restic.Tray_1.0.0_x64-setup.exe --repo nayuengin/restic-tray

Frequently asked questions (Q&A)

Direct answers on encryption, PC loss recovery, Windows auto-start, Unity excludes, and privacy. See all 10 Q&As & support policy

Can Cloudflare read my backed-up files?

No. Restic encrypts all file contents, filenames, and metadata on your PC before uploading to R2 using AES-256-CTR with Poly1305-AES authentication, and your repository password never leaves your machine.

Can I restore my data if I lose my PC? What if I forget the repository password?

Yes, as long as you saved your Restic repository password outside the PC (you can always issue a new R2 API token in Cloudflare). Because credentials.dat is encrypted with Windows DPAPI tied to that specific PC and Windows user, losing the repository password makes encrypted backups permanently unrecoverable.

Does Restic Tray start automatically when I sign in to Windows?

Not automatically yet. Scheduled backups and overdue notifications only run while Restic Tray is running, so add a shortcut to restic-tray.exe --minimized inside your Startup folder (Win + R → shell:startup). See Start automatically on Windows sign-in.

Why is Unity’s Library folder excluded by default?

Regenerable Unity project-root outputs (Library, Temp, Logs, obj, Build, Builds, Assets\SerializedUdonPrograms) are excluded when useBasicExcludes is enabled to save storage and upload time. Folders with the same names inside Assets/ or Packages/ are still backed up.

Does Restic Tray send telemetry or contact any server besides my R2 bucket?

No. There is no author-operated server, no analytics or telemetry, and no built-in update checker. To get release alerts, use Watch → Custom → Releases on the GitHub repository.
