トラブルシューティング

SmartScreen 警告、再起動後の停止、DPAPI 復号エラー、R2 権限エラー、ロック延期、除外一致、MCP 拒否などの原因と解決方法です。

よくある症状と原因・対処の早見表です。各見出しで詳細手順を確認できます。

症状別の原因と対処早見表
症状 原因 すぐ試す対処
SmartScreen / Smart App Control 警告 初期リリース（v1.0.0）はコード署名なし SHA256SUMS.txt と gh attestation verify を確認後、「詳細情報 → 実行」（またはソースビルド）。
Windows 再起動後に自動バックアップが止まる 自動起動の自動登録は未実装 shell:startup に restic-tray.exe --minimized のショートカットを配置。
credentials.dat の復号エラー DPAPI が元の PC・Windows ユーザーに紐づく 設定 → 認証情報で R2 キーと元のリポジトリパスワードを再入力して保存。
バケット全体削除で 403 AccessDenied バケット限定 Object Read & Write に DeleteBucket 権限がない オブジェクトは空化済み。Cloudflare ダッシュボードから空バケットを削除。
除外パターン一致でバックアップ中止 基本または独自除外が対象フォルダ自体に一致 親フォルダ名や除外設定を見直すか、useBasicExcludes をオフ。
履歴に deferred（延期）が出る 別プロセス／他 PC がリポジトリロック保持（終了コード 11） 15 分後の自動再試行（最大 2 回）を待つか、他 PC 停止確認後に安全なロック解除。
MCP 破壊的操作が拒否される オプトイン無効（false）または確認引数不足 allowPrune / allowDeleteStorage / allowHandoff を有効化し dryRun: false と確認値を明示。
Google Drive 廃止エラーで起動停止 旧 config.json に "storageBackend": "googleDrive" が残存 該当行を削除して Cloudflare R2 を設定し再起動。

インストーラ実行時に SmartScreen / Smart App Control の警告が出る

原因: 初期リリース（v1.0.0）はコード署名なしで配布しているためです。

  • まず「チェックサム照合とビルド来歴証明」の手順で SHA256SUMS.txt と gh attestation verify を確認してください。
  • SmartScreen の警告画面（「Windows によって PC が保護されました」）では 詳細情報 → 実行 を選びます。
  • Windows 11 の Smart App Control が強制有効な環境では未署名バイナリがブロックされます。その場合は「ソースからビルド」をご検討ください。

PC を再起動してから自動バックアップが動いていない

原因: 現時点では Windows の自動起動をアプリ側で自動登録していません。定期バックアップと未実施通知はアプリが起動している間だけ動作します。

対処: Win+R で shell:startup を開き、"%LOCALAPPDATA%\Programs\Restic Tray\restic-tray.exe" --minimized へのショートカットを作成してください。

認証情報の復号エラーが出る（credentials.dat）

原因: config\credentials.dat は Windows DPAPI でその PC のその Windows ユーザーに紐づけて暗号化されています。別 PC へコピーした場合や Windows 再インストール後、ファイル破損時は復号できず、Restic Tray は元ファイルを誤って上書きしないよう明確なエラーで停止します。

対処: 設定 → 認証情報 で R2 のアクセスキー ID・シークレットアクセスキー・元のリポジトリパスワードを再入力して 認証情報を保存 してください。破損した credentials.dat が残って部分保存できない場合は、%LOCALAPPDATA%\io.github.nayuengin.restic-tray\config\credentials.dat を退避・削除してから 3 項目すべてを保存し直します。

Cloudflare R2 接続エラーや 403 AccessDenied

  • アカウント ID とバケット名の確認: 32 文字のアカウント ID に空白やスラッシュが混ざっていないか、バケット名が小文字で正確に一致しているかを 設定 → 保存先 のプレビュー URL（s3:https://<accountId>.r2.cloudflarestorage.com/<bucket>[/<prefix>]）で確認してください。
  • トークンの権限・期限切れ: Cloudflare ダッシュボードの Manage R2 API Tokens で、対象バケットに Object Read & Write 権限があることと有効期限（TTL）が切れていないことを確かめます。
  • バケット全体削除での 403 AccessDenied: バケット限定の Object Read & Write トークンでは、全オブジェクト削除と未完了マルチパート中止まで成功し、最後の DeleteBucket だけ 403 になります。空化済みの案内が出たあと、Cloudflare ダッシュボードから空のバケットを削除してください。

除外パターンが対象フォルダ自体に一致してバックアップが中止される

原因: D:\target\my-project のように、基本除外（target/ 等）や独自除外パターンが対象フォルダ自身のパスを含む場合、中身がゼロ件になるのを防ぐため実行前に中止します。

対処: 親フォルダ名や独自除外パターンを見直すか、フォルダ画面で 基本の除外パターンを有効にする をオフにしてください。

履歴に deferred（延期）と出る／リポジトリロック中

原因: 別プロセスや他の PC がリポジトリの排他ロックを保持しています（--retry-lock での終了コード 11）。

  • 定期バックアップは自動的に deferred として記録され、15 分後に最大 2 回まで再試行されます。
  • 強制終了などで古いロックが残った場合は、他 PC で Prune や検査が動いていないことを確認したうえで、アプリ側の安全なロック解除（または公式 CLI の restic unlock）を実行してください。

Unity の除外や複数 PC 引き継ぎでの警告

  • Library/ が入っていない: useBasicExcludes が有効な場合の正常動作です。生成キャッシュも送りたい場合だけ フォルダ 画面でオフにしてください。
  • Temp\UnityLockfile や .git で引き継ぎが止まる: 共有プロジェクトを引き渡す・引き継ぐ前に Unity エディタを閉じてください。.git を含むフォルダは複数 PC 引き継ぎ（projectKey）の対象外のため、Git で同期してください。

MCP のツール呼び出しが拒否される／繋がらない

  • 破壊的操作が拒否される: forget_prune、update_retention_policy、autoPruneAfterBackup、delete_r2_bucket、takeover_project は既定で無効です。必要な項目だけ config.json または設定画面でオプトインを有効にし（agent.allowPrune / allowDeleteStorage / allowHandoff）、dryRun: false と確認パラメータを明示してください。
  • 空配列エラー: 全体を対象にしたい場合は includePaths・targetIds・projectKeys を省略してください。[] を渡すと範囲誤拡大防止のためエラーになります。
  • 接続できない: 常駐アプリが閉じていてもヘッドレスで動くため、MCP クライアント設定の restic-tray.exe のパスが実在する実行ファイルと一致しているか確認してください。

起動時に Google Drive 廃止エラーが表示される

原因: v0.4–v0.7 時代の config.json に "storageBackend": "googleDrive" が残っている場合、意図しない保存先へ勝手に切り替わらないよう起動を停止します。

対処: %LOCALAPPDATA%\io.github.nayuengin.restic-tray\config.json から "storageBackend": "googleDrive" の行を削除し、Cloudflare R2 の設定を確認して再起動してください。既存の Google Drive 上のデータは標準の restic リポジトリのため、restic と rclone で直接取り出せます。
