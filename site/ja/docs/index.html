Restic Tray ドキュメント

Windows への導入、Cloudflare R2 の初期設定、日々の運用、MCP 連携、バックアップと復元、トラブルシューティングまでを網羅した公式ガイドです。

はじめに確認しておく前提
  • 対応環境: Windows 10 / Windows Server 2016 以降（x64）および TLS 1.2 以降。
  • 保存先: Cloudflare R2（restic 標準の S3 互換バックエンド）。
  • 画面言語: デスクトップ GUI および内蔵 MCP ツールの説明文は日本語対応です。
  • 非公式ソフトウェア: MIT ライセンスの独立 OSS であり、restic および Cloudflare とは関係ありません。

  3. 基本操作 — 対象フォルダの追加、Unity 対応の基本除外、スケジュール、定期復元確認、履歴の見方。
