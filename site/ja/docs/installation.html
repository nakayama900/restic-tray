導入と検証

Restic Tray v1.0.0 の入手、SHA-256 チェックサムとビルド来歴証明の確認、Windows サインイン時の自動起動設定を説明します。

動作環境

  • OS: Windows 10 / Windows Server 2016 以降（64-bit x64）。
  • TLS: TLS 1.2 以降（同梱する公式 restic.exe v0.20.0 の必須要件）。
  • 保存先: Cloudflare R2 バケットと API トークン（手順は「初期設定と Cloudflare R2」を参照）。
  • 追加ランタイム: 不要。配布パッケージは純 Rust のネイティブバイナリで、WebView2 や Visual C++ 再頒布可能パッケージの導入は要りません。

GitHub Releases からダウンロード

GitHub Releases から利用形態に合うパッケージを取得してください。3 形式すべてに、SHA-256 検証済みの固定バージョン公式 restic.exe v0.20.0 を同梱しています。

Restic Tray v1.0.0 Windows x64 配布形式一覧
配布形式 ファイル名 インストール先・特徴
NSIS インストーラ（推奨） Restic.Tray_1.0.0_x64-setup.exe %LOCALAPPDATA%\Programs\Restic Tray へユーザー単位で導入。常駐アプリや --mcp が動いていても安全に上書き更新できます。
MSI インストーラ Restic.Tray_1.0.0_x64_ja-JP.msi Windows Installer 形式（ユーザー単位導入）。
Portable ZIP Restic.Tray_1.0.0_x64-portable.zip 任意のフォルダに展開して restic-tray.exe を直接起動します（restic.exe を同梱）。

チェックサム照合とビルド来歴証明

初期リリースは未署名です（SmartScreen / Smart App Control）

初期リリースは コード署名なし で配布されます。初回実行時に Windows Defender SmartScreen の警告（「Windows によって PC が保護されました」）が表示される場合があります。必ず以下の検証を行ってから「詳細情報」→「実行」で起動してください。Windows 11 の Smart App Control が有効な環境では未署名バイナリがブロックされる場合があります。

同じリリースから SHA256SUMS.txt もダウンロードし、PowerShell で両方の検証を実行してください。

PowerShell 
# 1. 同じリリースの SHA256SUMS.txt と SHA-256 ハッシュを照合する
Get-FileHash -Algorithm SHA256 .\Restic.Tray_1.0.0_x64-setup.exe
Get-Content .\SHA256SUMS.txt

# 2. GitHub Artifact Attestation（ビルド来歴証明）を検証する（GitHub CLI `gh` が必要）
gh attestation verify .\Restic.Tray_1.0.0_x64-setup.exe --repo nayuengin/restic-tray

公式リリース配布物はすべて GitHub ホステッドランナー（.github/workflows/release.yml）でビルドされ、GitHub Artifact Attestations が付与されています。

Windows サインイン時の自動起動

定期バックアップを止めないための重要設定

現時点では、アプリ側で Windows の自動起動を登録する機能はありません。定期バックアップと未実施通知はアプリが起動している間だけ動作するため、PC 再起動後にアプリを起動しないままだとバックアップが止まります。

サインイン時にトレイへ格納した状態で自動起動させるには、スタートアップフォルダへショートカットを配置してください。

  1. Win + R を押し、shell:startup と入力して Enter を押します。
  2. 開いたスタートアップフォルダに、--minimized 引数を付けたショートカットを作成します。
ショートカットのリンク先 
"%LOCALAPPDATA%\Programs\Restic Tray\restic-tray.exe" --minimized

Portable ZIP 版を使っている場合は、展開した restic-tray.exe のパスに読み替えてください。

更新とアンインストール

  • 新リリースの通知: アプリ内に自動更新確認通信はありません。nayuengin/restic-tray の上部にある Watch → Custom → Releases を有効にしてください。
  • バージョンアップ: 新しい NSIS インストーラを検証のうえ実行すれば、常駐中・--mcp 稼働中でも安全に上書き更新できます。
  • アンインストール: アプリを削除しても %LOCALAPPDATA%\io.github.nayuengin.restic-tray\ と Cloudflare R2 上のバックアップデータは削除されません。完全に消去したい場合は手動で削除してください。

ソースからビルド（任意）

前提環境（Windows x64）: Rust stable（MSRV 1.95、x86_64-pc-windows-msvc）、Visual Studio C++ ビルドツール、PowerShell 7（pwsh）。インストーラも作る場合は NSIS（makensis.exe）、WiX Toolset 3.14（candle.exe / light.exe）、Python 3 も必要です。

PowerShell 
git clone https://github.com/nayuengin/restic-tray.git
cd restic-tray

# 固定バージョンの公式 restic.exe (v0.20.0) を取得し SHA-256 検証のうえ配置
pwsh -NoProfile -File scripts/download-restic.ps1

# 開発起動
cargo run

# リリースビルド (target/release/restic-tray.exe)
cargo build --release --locked
