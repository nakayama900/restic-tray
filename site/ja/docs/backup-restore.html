バックアップと復元の手順

テスト実行から初回バックアップ、GUI での全体・部分復元、新しい PC での復旧、公式 restic CLI 単体での復元手順をまとめています。

Restic Tray はフォルダごとに暗号化スナップショットを作成し、復元時に元のフォルダを直接上書きしません。保存先は標準 restic リポジトリ形式のため、GUI・MCP・新 PC・公式 restic CLI 単体のいずれからでも復元できます。

復元手段と安全ガード・展開先一覧
復元手段 必要なもの 安全ガードと出力先
GUI 復元（スナップショット画面） R2 認証情報を設定済みの Restic Tray fs_safety で検証された別フォルダへ展開。ドライブ直下（C:\）・..・システム領域を拒否。全体／カンマ区切り部分復元に対応。
MCP 復元（restore_snapshot） MCP クライアント + agent.allowRestore: true（既定） 検証済み targetDir へ全体または includePaths 指定復元。空配列 includePaths: [] は拒否。
新しい PC での復旧 新規 Restic Tray + R2 トークン + 元のリポジトリパスワード 同一のアカウント ID・バケット・プレフィックス・パスワードを再入力し、接続を確認後に復元。
公式 restic CLI 復元（アプリなし） 公式 restic.exe + R2 キー + リポジトリパスワード 標準 restic 形式でロックインなし。<復元先>\<ドライブ文字>\<元のパス> 配下に展開。

最初のバックアップ手順（テスト実行 → 本番）

  1. フォルダ画面で対象フォルダと 基本の除外パターンを有効にする の状態を確認します。
  2. 概要画面に戻り、まず テスト実行（Dry-Run）を押します。データをアップロードせずに restic backup --dry-run が走り、ファイル件数やキャッシュが正しく除外されているか確かめられます。
  3. 問題がなければ 今すぐバックアップ を実行します。有効なフォルダごとに 1 件ずつ暗号化スナップショットが作成されます（1 対象 = 1 スナップショット）。
  4. 完了後、設定 → スケジュール で自動バックアップを有効にし、Windows サインイン時の自動起動も済ませておくと安心です。

アプリの画面から復元する

  1. 左メニューの スナップショット を開き、R2 から読み込む（または 再読み込み）を押して一覧を取得します。
  2. 左の一覧から復元したいスナップショットを選びます。必要に応じて ファイル一覧を表示 や 差分を表示 で中身を確認できます。
  3. 復元セクションの 復元先フォルダ に、元の場所とは別の安全なフォルダ（例: D:\Restore\2026-11-26）を指定します。fs_safety により、ドライブ直下（C:\）、.. トラバーサル、未解決リパースポイント、C:\Windows・C:\Program Files などのシステム領域は自動的に拒否されます。
  4. 一部だけ復元したい場合: 一部だけ復元する（任意） にスナップショット内のパス（例: /D/Projects/SampleWorld/notes）をカンマ区切りで入力します（空欄なら全体復元）。MCP からは restore_snapshot の includePaths で同じ操作ができます。
  5. 復元する を押し、確認ダイアログで確定します。
復元後のフォルダ階層について

復元先フォルダの下には、元のドライブ文字を含む階層構造でファイルが展開されます（例: D:\Projects\SampleWorld のスナップショットを D:\Restore\2026-11-26 へ復元すると D:\Restore\2026-11-26\D\Projects\SampleWorld\... に配置されます）。元のフォルダを直接上書きすることはありません。

新しい PC で復旧する（PC 紛失・故障時）

PC の故障・紛失や Windows 再インストール後に別の PC から復旧する手順です。

  1. 新しい PC に Restic Tray をインストールします。
  2. 設定 → 保存先 に、元の PC と同じ Cloudflare R2 の アカウント ID・バケット・バケット内のフォルダ を入力して 保存 します。
  3. 設定 → 認証情報 に、有効な R2 API トークン（Cloudflare ダッシュボードで新しく発行したもので構いません）と、別の場所に控えておいた元のリポジトリのパスワード を入力して 認証情報を保存 します。
  4. 接続を確認 でリポジトリへアクセスできることと整合性を確かめます。
  5. スナップショット画面から必要なスナップショットを選び、別の復元先フォルダへ取り出します。

Restic Tray なしで復元する（公式 restic CLI）

保存先は標準の restic リポジトリのため、Restic Tray がなくても公式の restic コマンドだけで一覧確認と復元ができます。

  1. restic/restic Releases から Windows 版の公式 restic.exe を入手します。
  2. PowerShell で、現在のセッションの環境変数に R2 の接続先とアクセスキーを設定します。
PowerShell 
$env:AWS_ACCESS_KEY_ID = "<R2 のアクセスキー ID>"
$env:AWS_SECRET_ACCESS_KEY = "<R2 のシークレットアクセスキー>"
$env:AWS_DEFAULT_REGION = "auto"
$env:RESTIC_REPOSITORY = "s3:https://<アカウント ID>.r2.cloudflarestorage.com/<バケット名>/<プレフィックス>"
# プレフィックスを使っていない場合は末尾の /<プレフィックス> を省きます。
パスワードは PowerShell の履歴に残さない

リポジトリのパスワードは $env:RESTIC_PASSWORD に書かず、restic 実行時の対話プロンプトから入力するとコマンド履歴に残りません。

  1. スナップショット一覧を確認し、別のフォルダへ復元します。
PowerShell 
.\restic.exe snapshots
.\restic.exe restore <スナップショット ID> --target D:\Restore

復元されたファイルは D:\Restore\<ドライブ文字>\<元のパス>\... 配下に展開されます。手動でデータ整合性を確かめる場合は .\restic.exe check --read-data-subset=5% を実行します。
