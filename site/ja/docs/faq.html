よくある質問・サポート方針

暗号化、PC 紛失時の復旧、自動起動、Unity 除外、R2 料金、プライバシー、サポート方針と免責事項をまとめています。

よくある質問

Windows を起動したら自動で動きますか？

現時点では自動登録されません。定期バックアップと未実施通知はアプリが動いている間だけ働くため、Win + R → shell:startup に restic-tray.exe --minimized のショートカットを置いてください（サインイン時の自動起動）。

PC をなくしたら復元できますか？ パスワードを忘れたらどうなりますか？

リポジトリのパスワードを別の場所に控えてあれば、新しい PC から復元できます（R2 の API トークンは Cloudflare ダッシュボードで再発行できます）。credentials.dat は元の PC のその Windows ユーザーでしか復号できないため、パスワードを忘れると R2 上のバックアップは二度と復元できません。

Cloudflare はバックアップしたファイルの中身を読めますか？

読めません。ファイルの中身・ファイル名・メタデータはすべて送信前に PC 上で restic が AES-256-CTR と Poly1305-AES で暗号化し、パスワードは PC の外に出ません。

Unity の Library フォルダがバックアップに入っていないのはなぜですか？

Unity プロジェクト直下の Library、Temp、Logs、obj、Build、Builds、Assets\SerializedUdonPrograms は再生成できるキャッシュのため、容量と転送時間を節約する目的で既定で除外しています（useBasicExcludes: true）。Assets や Packages 内の同名フォルダは除外されません。生成物も残したい場合は フォルダ 画面で 基本の除外パターンを有効にする をオフにしてください。

Git のリポジトリもバックアップできますか？

できます。.git を含めてフォルダ全体が保存されます（除外されるのは一時ファイル .git/objects/pack/tmp_pack_* のみ）。ただし複数 PC の引き継ぎ機能（projectKey）は .git を含むフォルダには使えないため、コードの同期は Git で行ってください。

Cloudflare R2 の料金はどのくらいかかりますか？

最新の無料枠と単価は Cloudflare R2 Pricing を参照してください。R2 はエグレス（取り出し）料金が無料で、restic の重複排除と基本の除外パターンにより保存容量も抑えられます。なお無料枠でも R2 有効化時に支払い方法の登録が必要です。

インストーラで Windows SmartScreen の警告が出るのはなぜですか？

初期リリースはコード署名なしで配布しているためです。実行前に「チェックサム照合とビルド来歴証明」の手順で SHA256SUMS.txt と gh attestation verify を確認してください。

Cloudflare R2 以外の保存先、macOS/Linux、英語 UI に対応予定はありますか？

現在の対応範囲は Windows 10 / Windows Server 2016 以降（x64、TLS 1.2 以降必須）・Cloudflare R2・日本語 UI です。範囲外の要望も GitHub Issues でアイデアとして受け付けていますが、実装は約束していません。

自分の R2 バケット以外にデータを送信しますか？

送信しません。作者運営のサーバー、テレメトリ、更新確認通信はいずれもありません。

新しいバージョンが出たことをどう知ればよいですか？

アプリ内に自動更新確認はありません。GitHub リポジトリ nayuengin/restic-tray の上部にある Watch → Custom → Releases を有効にすると新リリースの通知を受け取れます。

サポート方針と免責

  • サポート対象バージョン: 最新リリースのみを対象とします。過去バージョンへの修正のバックポートは行いません。
  • SLA なし: オーナー（@nayuengin）の指揮のもと AI メンテナ体制によるベストエフォート運用であり、返信や修正の期限（SLA）は約束しません。
  • セマンティックバージョニング: SemVer に従い、破壊的変更はメジャーバージョンでのみ行います。変更内容と移行手順は CHANGELOG.md に記載します。
  • 対応範囲: Windows 10 / Windows Server 2016 以降（x64、TLS 1.2 以降必須）・Cloudflare R2・日本語 UI を前提としています。
  • バックアップ内容の免責: MIT ライセンスの無保証条項に加え、本アプリはバックアップの完全性および復元可能性を保証しません。定期的な復元確認機能や手動のテスト復元により、復元できることを利用者自身で確認してください。
  • セキュリティ報告: 脆弱性は公開 Issue ではなく、GitHub Private Vulnerability Reporting から非公開で報告してください。
