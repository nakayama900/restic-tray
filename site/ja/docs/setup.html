初期設定と Cloudflare R2 の準備

Cloudflare R2 バケットと最小権限 API トークンを作成し、Windows DPAPI で安全に認証情報を保存してリポジトリを初期化する手順です。

Restic Tray はバックアップの保存先として Cloudflare R2（S3 互換オブジェクトストレージ）を使用します。ここでは Cloudflare ダッシュボードで専用バケットと最小権限の API トークンを作成し、Restic Tray でリポジトリを初期化するまでを案内します。

Cloudflare R2 の有効化と料金条件

無料枠の範囲内で使う場合でも、Cloudflare 側の仕様により支払い方法（クレジットカード等）の登録が必要です。R2 は取り出し（エグレス）料金がかからないため、復元や定期的な読み戻し確認でも転送料を気にせず運用できます。最新の条件や画面項目名は Cloudflare R2 Pricing および R2 API Tokens ドキュメント を確認してください。

1. バックアップ専用バケットを作成する

  1. Cloudflare ダッシュボード（https://dash.cloudflare.com/）にログインし、左メニューの R2 Object Storage を開きます。
  2. Overview → Create bucket をクリックします。
  3. Bucket name を入力します（3–63 文字の英小文字 a-z、数字 0-9、ハイフン - のみ。先頭・末尾のハイフン不可。例: my-restic-backups）。
  4. Location（通常は既定の Automatic または最寄り地域の Location Hint）と Default Storage Class（通常は Standard）を確認し、Create bucket をクリックします。

2. 32 文字のアカウント ID を確認する

Restic Tray はアカウント ID から S3 互換エンドポイント（https://<ACCOUNT_ID>.r2.cloudflarestorage.com）を自動で組み立てます。32 文字の 16 進文字列である Account ID は次のいずれかで確認できます。

  • R2 の Overview 画面右側にある Account Details の Account ID
  • ダッシュボードの URL（https://dash.cloudflare.com/<ACCOUNT_ID>/r2/...）の <ACCOUNT_ID> 部分

3. 最小権限の R2 API トークンを作成する

  1. R2 の Overview 画面右側 Account Details にある API Tokens の横の Manage（または Manage R2 API Tokens）をクリックします。
  2. Account API tokens（ユーザー構成の変更に左右されにくく長期運用に向くため推奨）を選び、Create Account API token をクリックします。
  3. Token name に用途が分かる名前を付けます（例: restic-tray-main-pc）。PC ごとにトークンを分けておくと、紛失時に該当 PC 分だけ失効できて安全です。
  4. Permissions（権限）を下表の基準で選択します。
Cloudflare R2 API トークンの権限選択
権限 バケット限定 できること 推奨用途
Object Read & Write 可能（Specify bucket(s)） バックアップ、一覧取得、復元、整合性チェック、forget --prune、プレフィックス配下削除、バケット内の全オブジェクト削除（空化）。 通常のバックアップ運用（最小権限・推奨）。バケット本体の削除（DeleteBucket）のみ 403 AccessDenied になるため、空化後に Cloudflare ダッシュボードからバケットを削除します。
Admin Read & Write 不可（アカウント内の全 R2 バケット） 上記すべてに加え、Restic Tray からのバケット本体の一括削除。 アプリからバケット本体まで直接削除したい場合のみ（通常運用では非推奨）。
  1. Specify bucket(s) で Apply to specific buckets only を選び、手順 1 で作成したバックアップ専用バケットだけを指定します。
  2. TTL（有効期限）を Forever（無期限）または任意の期限に設定します（期限を設けた場合は期限切れ前に再発行して更新してください）。
  3. Create Account API Token をクリックし、完了画面に表示される Access Key ID と Secret Access Key を控えます。
アクセスキーは 1 度しか表示されません

Access Key ID と Secret Access Key は作成直後の画面で 1 度しか表示されません。控える前に画面を閉じた場合は、新しいトークンを発行し、不要になった古いトークンを Revoke / Delete してください。

4. Restic Tray に入力して初期化する

  1. Restic Tray を起動し、左メニューの 設定 を開きます。
  2. 次の対応表に沿って入力します。
Cloudflare R2 の値と Restic Tray 設定画面の対応表
Cloudflare 側の値 Restic Tray（設定画面）の入力欄 保存先
Account ID（32 文字の 16 進文字列） 保存先 → アカウント ID config.json（平文・非秘密）
作成した Bucket name 保存先 → バケット config.json（平文・非秘密）
任意（例: workstation、空欄ならバケット直下） 保存先 → バケット内のフォルダ config.json（平文・非秘密）
API トークンの Access Key ID 認証情報 → アクセスキー ID config\credentials.dat（Windows DPAPI 暗号化）
API トークンの Secret Access Key 認証情報 → シークレットアクセスキー config\credentials.dat（Windows DPAPI 暗号化）
利用者が決める強力なパスワード 認証情報 → リポジトリのパスワード config\credentials.dat（Windows DPAPI 暗号化）
リポジトリのパスワードは必ずアプリの外にも保管してください

config\credentials.dat は Windows DPAPI で「その PC のその Windows ユーザー」に紐づけて暗号化されるため、PC の故障・紛失や Windows 再インストール時には復号できません。R2 の API トークンは Cloudflare ダッシュボードで再発行できますが、リポジトリのパスワードを失うと R2 上の暗号化バックアップは二度と復元できません。パスワード管理ツールやオフラインの控えに必ず保存してください。

  1. 画面下部の保存バーで 保存（Ctrl+S）を押し、保存先設定を config.json に書き込みます。
  2. 認証情報欄の 認証情報を保存 を押し、Windows DPAPI で暗号化して保存します。
  3. 新しいバケット／プレフィックスの場合は リポジトリを作成 を実行します（他の PC で初期化済みのリポジトリへ繋ぐ場合は 接続を確認 を実行します）。
  4. 接続できたら フォルダ 画面で対象を追加し、概要 画面で テスト実行（Dry-Run）を確認してから 今すぐバックアップ を実行してください。

バケット内のフォルダ（プレフィックス）の使い分け

  • 1 台だけで使う場合: 空欄（バケット直下）でも、PC 名などのプレフィックス（既定は restic-windows、例: workstation）を付けても構いません。プレフィックスを付けると同じバケット内に用途別リポジトリを分けられ、プレフィックス配下だけの削除も行えます。
  • 複数 PC で共有リポジトリを使う場合: 共有する PC すべてで 同じアカウント ID・バケット・プレフィックス・リポジトリのパスワード を指定してください。API トークンは PC ごとに別々で構いません。

API トークンが漏洩したときの対処

万が一 Access Key ID や Secret Access Key をログや公開 Issue 等へ誤って貼ってしまった場合は、次の順で対処してください。

  1. Cloudflare ダッシュボードの R2 Object Storage → Manage R2 API Tokens で該当トークンを直ちに Revoke / Delete します。
  2. 新しい API トークン（Object Read & Write・対象バケット限定）を発行します。
  3. Restic Tray の 設定 → 認証情報 に新しい アクセスキー ID と シークレットアクセスキー を入力し、認証情報を保存 します（リポジトリのパスワード欄を空欄のまま保存すれば既存のパスワードが維持されます）。
  4. 接続を確認 を実行し、新しいトークンで接続できることを確かめます。
